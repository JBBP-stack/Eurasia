# Registro de fuentes históricas

Índice de trabajo para rastrear los hechos que inspiran EURASIA. Es documentación interna: los nombres reales y las referencias no se muestran durante la partida.

La URL directa es opcional. Cuando se investigue una noticia, basta con anotar aquí y en el campo origen del JSON el medio o institución, el título/documento y las fechas; si se encuentra, se añade también la URL. El JSON es la fuente canónica y este archivo se regenera con python tools/generar_registro_fuentes.py.
